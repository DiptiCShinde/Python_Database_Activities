# Python Learning Assignments

A collection of Python class assignments and practice activities covering programming fundamentals, problem-solving, and database connectivity.

## Notebooks

- **Class Assignment.ipynb** — Exercises using conditionals, loops, functions, input validation, and classes. Includes examples such as fee calculations, salary increases, and billing.
- **ClassAssignment1.ipynb** — Python practice exercises, including lambda functions.
- **Python connectivity Activity.ipynb** — Demonstrates connecting Python to Microsoft SQL Server with `pyodbc`. Includes examples of opening a connection, running SQL queries, retrieving records, and creating a simple restaurant billing activity that uses database menu and order data.

## Requirements

- Python 3
- Jupyter Notebook
- `pandas` for exercises that use it
- `pyodbc` and a configured SQL Server ODBC driver for the database activity

## Getting Started

1. Clone or download this repository.
2. Install the requirements you need for a notebook.
3. Open a notebook in Jupyter and run its cells.
